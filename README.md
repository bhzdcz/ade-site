# ADE site

Public product landing for **ADE** — a public open-source AI-native SDLC kit: artifacts on rails, humans at the gates.

- **Site:** [https://ade.ir](https://ade.ir)
- **Product kit:** [https://github.com/bhzdcz/ade](https://github.com/bhzdcz/ade)
- **Install:** [docs/how-to-run.md](https://github.com/bhzdcz/ade/blob/main/docs/how-to-run.md)
- **Kit map:** [docs/kit-map.md](https://github.com/bhzdcz/ade/blob/main/docs/kit-map.md)

Static page only (`index.html`, `styles.css`, `main.js`, `assets/`). Hosted on GitHub Pages. This repo is marketing for the kit; it is not the platform runtime and not a SaaS console.

## What the landing says

- **What** — public OSS playbook/kit you clone and run
- **Install** — clone → how-to-run → validate scripts
- **Docs / GitHub** — links into `bhzdcz/ade`
- **In v1** — templates, hooks, WidgetCo example, this site
- **Not in v1** — SaaS, paid setup, watcher, multi-harness, AI-DD

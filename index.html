Problem

Chat isn’t a handoff

Thread history is not a durable artifact. Decisions vanish; next agent (or human) starts cold.

Code isn’t the bottleneck

Models write fast. The hard parts are intent, review judgment, and keeping the loop honest.

Controls assume a human did every step

Classic process gates don’t fit AI-assisted work. You need rails that still leave humans at the gates.

Artifact chain

One loop. Artifacts on rails — not a roster of chat personas.

  1. intentWhat we want
  2. specWhat “done” means
  3. planHow we’ll ship
  4. diff+testsThe change
  5. REVIEWHuman judgment
  6. gatesMust-holds
  7. MaintainKeep it true
  8. new intentLoop again

How it runs

Git + Claude Code + PRs

Work lives in the repo. Agents propose; pull requests carry the diff. No separate console pretending to be the source of truth.

Hooks as must-holds

Automated checks hold the line on structure and contracts so humans spend attention on judgment, not ritual.

Humans at the gates

Review and accept/reject stay with people. The rail moves artifacts; it does not replace ownership.

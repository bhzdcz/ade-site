ADE

AI-native software development lifecycle (SDLC) kit — artifacts on rails, humans at the gates. Clone it and run.

View on GitHub Install Docs

What

ADE is a public open-source playbook/kit you clone and run in your own repo — not a hosted SaaS, not an agent IDE. Chat is not the source of truth; markdown artifacts on a rail are.

Chat isn’t a handoff

Thread chat fades; durable decisions need artifacts the next person can open.

Code isn’t the bottleneck

Models draft quickly; intent, review, and an honest loop usually take more care.

Controls assume a human did every step

Classic gates assume a human did every step. AI-assisted work still needs rails — and people at the gates.

Artifact chain

One loop. Artifacts move in order; people keep the judgment calls.

  1. intentWhat we want
  2. specWhat “done” means
  3. planHow we’ll ship
  4. diff+testsThe change
  5. REVIEWHuman judgment
  6. gatesmust-pass gates
  7. MaintainKeep it true
  8. new intentLoop again

Install

Three steps on a clean machine. Full detail in docs/how-to-run.md.

  1. Clone

    HTTPS first:

    git clone https://github.com/bhzdcz/ade.git
cd ade

  2. Read how-to-run

    Prerequisites, step-by-step flow, and validation live in the repo docs.

  3. Validate

    bash tests/validate-templates.sh
bash tests/validate-hooks.sh

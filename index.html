A few things
to know.

        

          

            Is ADE another coding agent?
            

              No. ADE is the workflow around Claude Code: artifacts, a small
              CLI, checks and review practices. Bring your own Claude Code
              access and existing development tools.
            

          

          

            Can I use it in an existing project?
            

              Yes. The installer targets an existing Git repository, preserves
              your settings and offers a dry run. It refuses to overwrite
              conflicting runtime files. Start with one small change.
            

          

          

            Do the hooks enforce production security?
            

              They check local workflow conditions for supported tools. Files
              and hooks are editable, so they do not authenticate reviewers or
              prevent every bypass. Use protected branches and deployment
              environments for real authorization. ADE's promote script is a
              simulation.
            

          

          

            Is the toolkit open source?
            

              The core repository is private today. A tested MIT release is the
              proposed direction. Public docs and examples are available here
              now; email Behzad to request toolkit access. The website source is
              public.
            

          

          

            What is included in the setup service?
            

              One workflow review, installation in one repository, one tailored
              example, a handover session and one follow-up within seven days.
              Application feature work, production deployment, unlimited support
              and AI subscription costs are excluded. Agree the scope and terms
              in writing before paying.
            

          

          

            Can I support the project?
            

              Yes. Try the example, share useful feedback, or contribute to the
              public website. Financial support options will appear when the
              maintainer has configured them.
              See ways to help.

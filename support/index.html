ADE is maintained by Behzad. The aim is a useful MIT core, funded by setup work and optional community support.

Useful contributions start small.

  • Try the worked example and tell me where it feels unclear.
  • Send a workflow problem you want ADE to solve.
  • Contribute to or star the public website repository. The toolkit source is currently private.
  • Share the public docs with someone who reviews AI-assisted code.
